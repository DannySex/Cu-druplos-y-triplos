# Cuádruplos y triplos

Abrir con Live Server (los módulos ES no cargan con doble clic en `index.html`).

```
cuadruplos-triplos/
├── index.html
├── README.md
├── css/
│   └── styles.css
└── js/
    ├── main.js        # eventos y flujo principal
    ├── ui.js          # render de tablas, resultado y alertas
    ├── analyzer.js    # pipeline completo
    ├── tokenizer.js   # análisis léxico
    ├── parser.js      # análisis sintáctico (árbol)
    ├── generator.js   # cuádruplos y triplos
    └── evaluator.js   # cálculo del resultado
```
